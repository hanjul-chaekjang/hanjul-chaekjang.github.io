채널 업로더

Channel Uploader · YouTube API Services 를 사용합니다 (uses YouTube API Services)

채널 업로더는 유튜브 채널 「논문 한 줄」과 「이야기 책장」 운영자가 직접 만든 영상을 자기 채널에 올리기 위해서만 쓰는 개인용 도구입니다. 외부 사용자에게 제공하지 않습니다.

하는 일

  • 운영자 본인의 유튜브 채널에 쇼츠 영상과 제목·설명을 업로드하고 공개 시간을 예약합니다.
  • 업로드가 제대로 됐는지 확인하기 위해 본인 채널 정보를 읽습니다.

Channel Uploader is a private, single-operator tool used only to upload the operator's own short videos to the operator's own YouTube channels ("논문 한 줄", "이야기 책장"). It is not offered to other users.
