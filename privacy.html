개인정보처리방침

시행일 2026-11-26

1. 누가 쓰나요

채널 업로더는 채널 운영자 본인만 사용합니다. 다른 사람의 Google 계정으로 로그인하지 않으며, 다른 사람의 개인정보를 수집하지 않습니다.

2. 어떤 정보에 접근하나요

  • YouTube Data API 를 통해 운영자 본인 채널에 영상을 업로드하는 권한(youtube.upload)
  • 업로드 결과 확인을 위해 본인 채널의 기본 정보를 읽는 권한(youtube.readonly)

3. 어떻게 저장하나요

로그인 후 받은 인증 토큰은 운영자 개인 컴퓨터에만 저장되며 외부 서버로 보내지 않습니다. 시청자 정보, 댓글, 구독자 정보는 수집·저장하지 않습니다.

4. 제3자 제공

어떤 정보도 제3자에게 판매하거나 제공하지 않습니다.

5. 권한 철회

Google 계정의 보안 설정 → 서드 파티 앱 액세스에서 언제든 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 작동하지 않습니다.

6. Google 정책

이 도구는 YouTube API 서비스를 사용하며 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.

7. 문의

각 채널 정보 페이지의 연락처로 문의해 주세요.

Privacy Policy (English)

Channel Uploader is used solely by the channel operator. It does not sign in other users or collect anyone else's personal data. It accesses YouTube Data API scopes youtube.upload (to upload the operator's own videos) and youtube.readonly (to confirm uploads on the operator's own channel). OAuth tokens are stored only on the operator's personal computer and are never sent to any other server. No viewer, comment, or subscriber data is collected, stored, sold, or shared. Access can be revoked at any time at Google Account permissions. This application uses YouTube API Services and complies with the YouTube Terms of Service and the Google Privacy Policy.
